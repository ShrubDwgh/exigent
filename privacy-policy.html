Emergency Card NFC

Kebijakan Privasi

Terakhir diperbarui: 1 Oktober 2026

1. Pendahuluan

Emergency Card NFC ("kami", "aplikasi") berkomitmen melindungi privasi Anda. Kebijakan ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi data pribadi Anda saat menggunakan layanan kartu darurat berbasis NFC kami.

Dengan menggunakan layanan ini, Anda menyetujui praktik yang dijelaskan dalam kebijakan ini.

2. Data yang Kami Kumpulkan

Kami mengumpulkan beberapa jenis data berikut:

  • Data Akun: Nama, alamat email, foto profil (jika login dengan Google), dan informasi autentikasi lainnya.
  • Data Medis Darurat: Golongan darah, alergi, kondisi medis, obat rutin, dan catatan medis lain yang Anda isi secara sukarela.
  • Data Kontak Darurat: Nama, nomor telepon, dan hubungan Anda dengan kontak darurat yang Anda daftarkan.
  • Data Identitas: Dokumen identitas (KTP/SIM/Paspor) jika Anda mengunggahnya untuk verifikasi darurat.
  • Data Lokasi: Lokasi terkini Anda, hanya jika Anda memberikan izin melalui browser saat kartu dipindai.
  • Data Teknis: Alamat IP, jenis perangkat, dan log aktivitas untuk keamanan sistem.

3. Bagaimana Kami Menggunakan Data Anda

  • Untuk Fungsi Darurat: Menampilkan data medis Anda kepada penolong (petugas medis, orang awam) saat kartu NFC Anda dipindai.
  • Untuk Autentikasi: Memverifikasi identitas Anda saat login dan mengelola akun.
  • Untuk Keamanan: Mendeteksi aktivitas mencurigakan dan mencegah penyalahgunaan.
  • Untuk Peningkatan Layanan: Analisis anonim untuk mengembangkan fitur baru.

4. Siapa yang Bisa Mengakses Data Anda

Data medis Anda dapat diakses oleh:

  • Anda sendiri melalui dashboard pribadi Anda.
  • Penolong (siapa pun yang memindai kartu NFC Anda), tetapi hanya data yang Anda izinkan untuk ditampilkan (Anda bisa mengatur ini di menu Pengaturan → Perizinan).
  • Tim Emergency Card NFC, hanya untuk keperluan dukungan teknis dan hanya dengan persetujuan tertulis dari Anda.

Kami TIDAK PERNAH menjual data Anda kepada pihak ketiga untuk tujuan komersial.

5. Keamanan Data

Kami menggunakan langkah-langkah keamanan standar industri:

  • Enkripsi data saat transit (HTTPS) dan saat tersimpan (at-rest encryption).
  • Row Level Security (RLS) pada database untuk memastikan setiap pengguna hanya bisa mengakses data miliknya sendiri.
  • Otentikasi aman melalui Supabase Auth (termasuk opsi login dengan Google).
  • Audit log untuk setiap akses ke data sensitif.

6. Berapa Lama Kami Menyimpan Data

  • Data akun & medis: Selama akun Anda aktif. Jika Anda menghapus akun, semua data dihapus permanen.
  • Log aktivitas: Maksimal 90 hari, kemudian dihapus otomatis.
  • Data anonim untuk statistik: Dapat disimpan tanpa batas waktu karena tidak bisa dihubungkan kembali ke Anda.

7. Hak Anda (Sesuai UU PDP No. 27 Tahun 2022)

Anda memiliki hak-hak berikut:

  • Hak Akses: Melihat semua data yang kami simpan tentang Anda.
  • Hak Koreksi: Memperbaiki data yang tidak akurat.
  • Hak Penghapusan: Menghapus akun dan semua data Anda (fitur "Hapus Akun" tersedia di Pengaturan).
  • Hak Portabilitas: Meminta salinan data Anda dalam format yang dapat dibaca mesin.
  • Hak Menarik Persetujuan: Menarik persetujuan penggunaan data kapan saja.
  • Hak Mengajukan Keluhan: Kepada kami atau kepada otoritas pengawas PDP.

8. Cookie dan Teknologi Serupa

Kami menggunakan cookie dan penyimpanan lokal (localStorage) untuk:

  • Menjaga sesi login Anda tetap aktif.
  • Menyimpan preferensi bahasa Anda.
  • Menyimpan pengaturan visibilitas data kartu Anda.

Anda dapat menghapus cookie kapan saja melalui pengaturan browser Anda.

9. Perubahan Kebijakan

Kami dapat memperbarui kebijakan ini dari waktu ke waktu. Perubahan signifikan akan kami beritahukan melalui email atau notifikasi di aplikasi. Tanggal "Terakhir diperbarui" di bagian atas akan menunjukkan kapan revisi terakhir dilakukan.

10. Kontak

Jika Anda memiliki pertanyaan tentang kebijakan privasi ini, silakan hubungi kami melalui:

  • Pusat Bantuan: Tersedia di menu Akun → Pusat Bantuan
  • Hubungi CS: Tersedia di menu Akun → Hubungi CS Emergency Card NFC
